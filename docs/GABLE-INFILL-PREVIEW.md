# Gable Infill Preview

This local 0.1.16.110021 update closes the workbench roof's gable ends.

Open the bench and cycle View to gables. Choose each end separately. Match walls
uses the cob or framed wall course below; other choices are raw or limewashed cob,
raw or limewashed daub, hanging tiles, or Open. Daub includes posts, rails and
raking timbers. Explicit choices use the selected roof wood. The clipboard's roof
page has the same settings.

Turn on the preview, check the materials bill and build. The angled top follows
the roof, including mansard bends and changes to pitch or height. Panels need the
ordinary wall materials listed in the bill, plus timber for framed daub. Rework
uses the existing material reuse and return system.

The separate five-house save shows pale cob gables, a raised slate roof, tile-hung
gables on the clay house, and a timber-framed daub end. The last house keeps its
original workbench roof for comparison. Earlier preview worlds are preserved.

Existing saved drawings keep open gables until you select infill. Existing wall
blocks and windows remain in place. You can remove an infill panel and fit an
ordinary window in its place; rebuilding keeps that independent window. The floor
and roof bounds are still rectangular, with the same 1,024-cell limit. Side knee
walls beneath raised eaves remain separate building work.

This is a local preview, not a publication. Native captures and automated checks
are separate from your gameplay and visual review.
